# Changelog

All notable changes to the VTX constants package will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2025-10-28

### Added
- Initial constants for VTX format v1.0
- File header constants (magic bytes, sizes, offsets)
- Record format bitmask constants
- Record size constants
- Compression type constants
- Footer constants
- Helper functions: `getRecordSize()`, `getVersionString()`, `hasSensor()`
