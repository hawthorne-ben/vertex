# Web App Changelog

All notable changes to the Vertex web platform will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2025-10-28

### Added
- Initial alpha release
- User authentication with Clerk and Supabase
- CSV file upload and parsing
- Interactive data visualization with Plotly.js and uPlot
- Ride analysis with statistics and metrics
- File management (upload, delete, organize)
- Dashboard with recent rides and overview
- Responsive design with Tailwind CSS
- Dark mode support (system-based)
- Background job processing with Inngest
- Real-time data processing

### Technical Details
- Next.js 15.0 with App Router
- TypeScript for type safety
- Supabase for database and auth
- Clerk for authentication UI
- Plotly.js and uPlot for data visualization
- Inngest for background jobs
- Tailwind CSS for styling
- CSV parsing with PapaParse
- Signal processing with fili and simple-statistics
- Vercel deployment ready
